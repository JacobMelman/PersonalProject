# ReproDesk (Phase 0): установка и запуск

Всё нужное лежит в этой папке. Установка расширения занимает 2 минуты и не требует прав администратора. Для демо-магазина нужен Node.js или Python 3; без них можно показать встроенные примеры сессий.

## Что в папке

| Папка / файл | Зачем |
| --- | --- |
| `ReproDesk-extension/` | Само расширение для Chrome (уже собрано, внутри лежит `manifest.json`) |
| `demo-shop/` | Демо-магазин Northwind Gear с двумя намеренными багами и файлами запуска |
| `docs/DEMO_SCRIPT.md` | Сценарий показа по шагам, с репликами |
| `INSTALL_AND_RUN.md` | Эта инструкция |

## 1. Что нужно

- **Google Chrome 116 или новее** на Windows 10/11, macOS или Linux.
- **Для демо-магазина:** Node.js 18+ ([nodejs.org](https://nodejs.org), версия LTS) **или** Python 3. Ставить пакеты (`npm install`) не нужно.
- Интернет не нужен ни расширению, ни магазину.

## 2. Установка расширения

1. Перенесите всю папку в постоянное место, например `~/ReproDesk` или `C:\ReproDesk`. Chrome читает расширение прямо из `ReproDesk-extension/`, поэтому папку потом не удаляйте и не переносите.
2. Откройте в Chrome адрес `chrome://extensions`.
3. Справа вверху включите **Developer mode** (Режим разработчика).
4. Нажмите **Load unpacked** (Загрузить распакованное расширение) и выберите папку **`ReproDesk-extension`**.
5. Нажмите значок пазла на панели Chrome и закрепите **ReproDesk (Phase 0 spike)** булавкой.

При следующих запусках Chrome может предлагать отключить расширения в режиме разработчика. Это обычное предупреждение для расширений не из Chrome Web Store: просто закройте его.

**Горячие клавиши** (меняются на странице `chrome://extensions/shortcuts`):

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| Сохранить последний реплей | Alt+Shift+R | ⌥⇧R |
| Добавить маркер (в Repro Session) | Alt+Shift+M | ⌥⇧M |
| Сделать скриншот | Alt+Shift+S | ⌥⇧S |

Start / Finish для Repro Session есть кнопками в боковой панели; клавишу для них можно назначить самому на той же странице.

## 3. Запуск демо-магазина

| Система | Как запустить |
| --- | --- |
| macOS | Двойной клик по `demo-shop/start-demo-shop.command`. В первый раз macOS может не открыть файл из интернета: клик правой кнопкой → **Open** → **Open**. |
| Windows | Двойной клик по `demo-shop/start-demo-shop.bat`. |
| Linux | В терминале: `./demo-shop/start-demo-shop.sh` |
| Вручную | В папке `demo-shop`: `node server.mjs` или `python3 server.py` |

Магазин откроется в браузере по адресу **http://localhost:5173/**. Он доступен только с этого компьютера. Остановить: закрыть окно терминала или нажать Ctrl+C.

Если порт 5173 занят, укажите другой: `node server.mjs 5180`, и откройте http://localhost:5180/.

## 4. Первый запуск: проверка за 2 минуты

1. Откройте магазин http://localhost:5173/.
2. **Кликните значок ReproDesk** на панели Chrome. Откроется боковая панель со статусом **ARMED**, на значке появится бейдж ON. С этого момента записывается только эта вкладка, и только на этом компьютере.
3. Подождите 10–15 секунд, походите по магазину, добавьте пару товаров в корзину.
4. Нажмите **Save last replay** (или Alt+Shift+R). Сохранится последний отрезок, и откроется отчёт: видео, таймлайн и шаги воспроизведения.

Если всё это получилось, установка в порядке.

**Перед показом** выставьте в боковой панели (шестерёнка → Settings): окно реплея **90s**, хвост **3s**, Pre-session context **30s**, **Open report after saving = On**. Полный сценарий показа: `docs/DEMO_SCRIPT.md`.

## 5. Без демо-магазина: готовые примеры

Если Node.js и Python поставить нельзя или что-то не запускается, в расширении есть заранее записанный прогон того же магазина. В боковой панели: **Settings → Sample data → Load sample sessions** (на пустом экране есть кнопка **Try with sample sessions**). Появятся две сессии с меткой Sample, и с ними работает всё: отчёт, размытие на скриншотах, маски на видео, экспорт. Убрать их: **Remove sample sessions**.

## 6. Если что-то пошло не так

| Что видно | Что сделать |
| --- | --- |
| Клик по значку ничего не дал | Активна должна быть обычная вкладка `http(s)`, не `chrome://` и не новая пустая. Кликните ещё раз. Если в панели статус ERROR, причина написана в красном блоке. |
| Статус PRIVACY PAUSED после перезагрузки или перехода | Это защита: после перехода расширение заново спрашивает разрешение. Кликните значок на этой вкладке ещё раз. |
| «Saved without video» | После включения нужно 10–15 секунд, чтобы набрался буфер. |
| Значка не видно на панели | Значок пазла → закрепите ReproDesk. |
| При экспорте Chrome спрашивает про несколько файлов | Нажмите Allow. Чтобы не было отдельного диалога на каждый файл, выключите «Ask where to save each file» в `chrome://settings/downloads`. |
| Магазин не открывается | Проверьте, что окно с сервером открыто и в нём нет ошибки. Порт занят: запустите на другом (раздел 3). |
| macOS: «permission denied» при запуске `.command` | В Терминале: `chmod +x demo-shop/start-demo-shop.command`, затем снова двойной клик. |

Сведения для отладки: Settings → Diagnostics → **Copy diagnostics JSON**.

## 7. Обновление и удаление

- **Обновить:** замените содержимое `ReproDesk-extension/` новой версией и нажмите ↻ у ReproDesk на `chrome://extensions`.
- **Удалить:** `chrome://extensions` → ReproDesk → **Remove**. Вместе с расширением удаляются все записанные сессии.

## Коротко о приватности

ReproDesk ничего не записывает, пока вы не кликнете значок на конкретной вкладке. Записывается только эта вкладка. Нажатия клавиш, буфер обмена и введённые значения не собираются. Всё хранится на этом компьютере, пока вы сами не нажмёте Export. Перед отправкой отчёта чувствительные данные на скриншотах и в видео можно размыть, и оригинал при этом не меняется.
