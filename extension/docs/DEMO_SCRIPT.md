# Сценарий демо ReproDesk (5-7 минут)

**История:** QA-инженер проверяет магазин *Northwind Gear* (демо-приложение из этого репозитория). В нём два намеренных бага:
1. промокод `SUMMER20` показывает скидку, но **итог не уменьшается**;
2. кнопка **Place order** всегда отвечает ошибкой **E-4021**.

Идея показа: «баг нашли - и разработчик получает готовое доказательство, а не пересказ по памяти».

## Подготовка (один раз, 3 минуты)
1. Установите расширение (см. `INSTALL.txt`, раздел 2) и **закрепите значок** ReproDesk.
2. Запустите демо-магазин: `cd extension && npm install && npm run demo:site` -> http://localhost:5173/
3. В боковой панели (значок шестерёнки) выставьте: окно реплея 90 s, хвост 3 s, pre-session 30 s, «Open report after saving» = On.
4. Закройте лишние вкладки и уведомления, масштаб страницы 100%. Откройте http://localhost:5173/.

## Ход показа
| # | Что делаете | Что говорите |
|---|---|---|
| 1 | Откройте магазин. Покажите панель: **INACTIVE** («Ready when you are»). | «Расширение ничего не пишет, пока я явно не включу его. Это требование Chrome и наш принцип». |
| 2 | **Клик по значку ReproDesk.** Панель открывается, статус **ARMED**, бейдж ON. Покажите чипы *Local only / No keystrokes / This tab only*. | «Включил на этой вкладке. Пишется только она, всё локально, клавиши и буфер обмена не собираются». |
| 3 | Походите по магазину: добавьте рюкзак, палатку, фонарь. Покажите шкалу **Rolling buffer** - она заполняется до 90 с. | «Идёт скользящий буфер: хранится только последние 90 секунд. Старое стирается само». |
| 4 | Нажмите **Save last replay** (или Alt+Shift+R). Появится тост «Trigger accepted», затем «Replay saved». | «Если баг случился неожиданно - одно нажатие сохраняет то, что уже произошло. Переписывать шаги по памяти не нужно». |
| 5 | Перейдите в корзину и нажмите **Start Repro Session**. Таймер идёт, статус **REC**. | «А если баг известен и путь длинный - запускаю сессию. 30 секунд до старта сохраняются отдельным блоком». |
| 6 | Введите `summer20`, **Apply**. Скидка -$74.40, а **Total** не изменился. В поле маркера введите «Промокод не уменьшает итог» -> **Add marker**. | «Вот баг №1. Маркер с автоскриншотом, не прерывая работу». |
| 7 | **Checkout**, заполните форму (имя, email, карта `4242 4242 4242 4242`, CVV), **Place order**. Появится ошибка E-4021. Маркер «Place order падает». | «Баг №2. Обратите внимание: что я печатал и данные карты в отчёт не попадают - клавиши не пишутся, а в таймлайне только действия». |
| 8 | Откройте новую пустую вкладку и вернитесь. Покажите **PRIVACY PAUSED**. | «Ушёл на другую вкладку - запись и сбор действий сразу на паузе. Чужой контент не сохраняется. Вернулся - продолжилось». |
| 9 | **Finish & review**. Открывается отчёт. | |
| 10 | В Review покажите: **видео**, живой **таймлайн** (строка подсвечивается по ходу видео; клик по строке перематывает), **шаги воспроизведения** (собраны из действий, без ИИ), **маркеры**, **скриншоты**. | «Разработчик видит и пиксели, и точные шаги. Expected result заполняет человек - мы не выдумываем ожидаемое поведение». |
| 11 | Заполните Title / Actual / Expected. Выберите **Evidence ZIP + HTML + Word**, нажмите **Export selected**. Откройте HTML-отчёт. | «Один клик - три формата. В ZIP лежат видео, скриншоты, события и manifest с хешами». |
| 12 | Откройте **Settings** в панели: окно, хвост, AFK, диагностика. | «Всё настраивается профилем цели; есть диагностика для пилота». |

## Если что-то пошло не так
* Панель показывает **ERROR** - прочитайте причину в красном блоке; чаще всего вкладка закрыта или это страница `chrome://`.
* После перезагрузки страницы статус **PRIVACY PAUSED** - кликните значок на вкладке ещё раз (или нажмите *Remember site* заранее).
* Нет видео в отчёте - сессия сохранена без видео (буфер был пуст); подождите 10-15 секунд после включения.
