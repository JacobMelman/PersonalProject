REPRODESK - PHASE 0 (технический спайк браузерного расширения)
================================================================
Версия сборки: 0.0.1   |   Спецификация: Product Concept & Pre-MVP v0.2.4
ID расширения при установке "из папки" всегда одинаковый: fnjljfngnjfnijhpocjnigkmhobjpggf

Это НЕ готовый продукт, а рабочая сборка для Phase 0: на ней вы проверяете, что
захват вкладки, кольцевой буфер, приватность, восстановление и экспорт работают
в вашей среде, и присылаете результаты (см. раздел 9).


1. ТРЕБОВАНИЯ
-------------
- Google Chrome последней стабильной версии (минимум 116; Edge в Phase 0 не проверялся).
- Windows 10/11, macOS или Linux. Права администратора не нужны.
- Для установки из готового архива Node.js НЕ нужен.
- Для сборки из исходников и запуска тестов: Node.js 20+ и npm.
- Для экспорта в DOCX/XLSX нужен только просмотрщик (Word/Excel/LibreOffice) на вашей стороне.


2. УСТАНОВКА (быстрый способ, без Node.js)
------------------------------------------
1) Скачайте файл  extension/releases/reprodesk-phase0-v0.0.1.zip  из репозитория
   (ветка claude/jolly-bell-zrcp27) и распакуйте его в постоянную папку, например
   C:\Tools\reprodesk  или  ~/reprodesk . После распаковки в папке должен лежать файл manifest.json.
   (Папку не удаляйте и не переносите: Chrome читает расширение прямо из неё.)
2) В Chrome откройте  chrome://extensions
3) Справа вверху включите "Режим разработчика" (Developer mode).
4) Нажмите "Загрузить распакованное расширение" (Load unpacked) и выберите папку с manifest.json.
5) Нажмите значок пазла в панели Chrome и закрепите (pin) "ReproDesk (Phase 0 spike)".
6) Горячие клавиши (меняются в chrome://extensions/shortcuts):
      Alt+Shift+R  сохранить последний реплей
      Alt+Shift+M  добавить маркер (во время Repro Session)
      Alt+Shift+S  сделать скриншот
   Chrome разрешает расширению только 3 клавиши по умолчанию, поэтому "Start / finish Repro
   Session" клавиши не имеет: назначьте её сами на той же странице (например Alt+Shift+P);
   Start/Finish всегда есть и кнопками в боковой панели.


3. УСТАНОВКА ИЗ ИСХОДНИКОВ (по желанию)
---------------------------------------
    cd extension
    npm install
    npm run build          # результат в папке dist/ ; загружайте именно её (шаги 2-5 выше)
    npm test               # юнит-тесты
    npm run test:e2e       # сквозные тесты в настоящем Chromium (нужен Playwright 1.56 и его браузер)
    npm run package        # собрать zip в releases/
Обновление: пересоберите, затем на chrome://extensions нажмите кнопку обновления у расширения.


4. КАК ПОЛЬЗОВАТЬСЯ (главное правило)
-------------------------------------
Chrome разрешает захват вкладки только после явного действия пользователя. Поэтому:

   ВКЛЮЧЕНИЕ = ОДИН КЛИК ПО ЗНАЧКУ REPRODESK НА ВКЛАДКЕ С ТЕСТИРУЕМЫМ ПРИЛОЖЕНИЕМ.

После клика открывается боковая панель, а значок получает бейдж "ON" (Armed). Дальше:
- Armed: идёт скользящая запись только этой вкладки (по умолчанию последние 90 секунд,
  старое удаляется само). Нашли баг -> "Save Last Replay" (или Alt+Shift+R). Реплей закрепляется,
  через 5 секунд "хвоста" открывается страница Review.
- Для известного бага: "Start Repro Session" -> воспроизводите -> "Add Marker" (маркеры с
  автоскриншотом) -> "Finish". Перед стартом автоматически сохраняются 30 секунд контекста
  (Pre-session Context), показываются в Review отдельным блоком (можно убрать).
- Состояния видны всегда: бейдж + крупный статус в панели (текстом, не только цветом):
  INACTIVE / ARMED / REC + таймер / SCREENSHOTS ONLY / PRIVACY PAUSED / PAUSED-manual /
  AFK / TARGET ENDED / ERROR-NOT RECORDING.
- Privacy Pause: при переходе на другую вкладку или на другой сайт запись и сбор действий
  приостанавливаются автоматически, чужое содержимое не сохраняется; при возврате на
  тестируемую вкладку продолжается само (если не нажата ручная Pause).
- AFK: экран заблокирован -> сразу пауза; нет активности 10 минут (настраивается) -> пауза.
  Armed продолжится сам при возвращении, Repro Session ждёт вашего нажатия "Resume recording".
- Закрыли вкладку/упал браузер: Target Ended / Recovered Session - то, что уже записано, не
  теряется, а помечается честно.
- Уход на другой домен (SSO, платёжная форма): запись и сбор действий ставятся на паузу
  (PRIVACY PAUSED) сразу, содержимое чужого домена не сохраняется. Когда вы вернулись, Chrome
  уже отозвал временное разрешение activeTab, поэтому есть два пути: (а) кликнуть значок
  ReproDesk на вкладке ещё раз - это перепроверка, запись продолжится; (б) один раз нажать
  в панели "Remember this site" и разрешить доступ к этому сайту в окне Chrome - тогда после
  любых перезагрузок и возвратов сбор продолжается сам. Для одностраничных приложений (SPA) и
  переходов внутри одного origin обычно хватает активной сессии без (б).
- Содержимое iframe того же (одобренного) origin и Shadow DOM попадает в таймлайн; iframe чужого
  origin виден только на видео (так задумано политикой приватности).
- Новое окно/вкладка (popup, SSO): видео не переносится "молча" - панель покажет Privacy Pause.
  Кликните значок ReproDesk на новой вкладке, чтобы перенести на неё захват (это и есть
  re-arm; он работает только внутри разрешённых сайтов).

Отчёт (страница Review): заполните Title / Actual / Expected / Notes (Expected всегда пишете вы),
выберите форматы (HTML, TXT, MD, DOCX, XLSX, ZIP) и нажмите "Export selected" - все файлы
создаются за одно действие. ZIP = полный Evidence Package: replay.webm, скриншоты, events.json,
session.json, report.* и manifest.json с SHA-256. Также есть "Copy as Markdown / Plain Text"
для вставки в Jira/Azure DevOps.

ВАЖНО про приватность: клавиши, буфер обмена, значения полей ввода НЕ собираются, URL
сохраняется как origin+path (без query и #). Но видео - это пиксели: всё, что видно на экране
тестируемой вкладки (имена, суммы), попадёт в видео и скриншоты. Просматривайте перед отправкой.
Все данные хранятся локально в профиле Chrome (IndexedDB + OPFS расширения); наружу ничего
не отправляется. Удаление: кнопка "✕" в списке сессий / "Delete this session" в Review,
либо удаление расширения.


5. БЫСТРЫЙ ТЕСТ НА https://practicesoftwaretesting.com/
-------------------------------------------------------
1) Откройте https://practicesoftwaretesting.com/ в Chrome, кликните значок ReproDesk -> ON.
2) Походите по сайту ~30 секунд (поиск, карточка товара, "Add to cart", корзина).
3) На странице входа введите тестовую учётку, указанную на самом сайте, НО не отправляйте
   лишнего. Позже проверьте в Review/ZIP (events.json): пароль и введённый текст отсутствуют.
4) Нажмите Save Last Replay (Alt+Shift+R). В Review проверьте: видео играет, шаги
   ("Click button ...", "Navigate to /checkout/...") сформированы, нет query/# в адресах.
5) Повторите как Repro Session с маркерами; переключитесь на другую вкладку (должен появиться
   PRIVACY PAUSED), вернитесь (запись продолжится); закройте вкладку во время сессии
   (должна сохраниться как Target Ended).
6) Экспортируйте все форматы и откройте DOCX/XLSX.

Если на этом сайте вы записываете сценарий через Playwright codegen, его можно проиграть с уже
включённым ReproDesk (нужен Node.js):
    npx playwright codegen https://practicesoftwaretesting.com/
Скопируйте сгенерированные действия в файл, например my-steps.mjs:
    export default async function (page) {
      // вставьте сюда код из codegen (без строк запуска браузера, "page" уже открыт на нужном URL)
    }
Запуск (откроется Chromium с расширением, оно включится само, сценарий выполнится, реплей сохранится):
    cd extension && npm install
    npm run demo -- --url https://practicesoftwaretesting.com/ --steps ./my-steps.mjs
Добавьте  --repro  чтобы писать Repro Session вместо Instant Replay. Это тестовая сборка:
она выдаёт себе доступ к указанному сайту и обходит клик по значку; для обычной работы
используйте установку из раздела 2.
(Примечание: в среде, где я готовил сборку, этот сайт был недоступен по сети, поэтому на нём
сценарий не прогонялся; весь пайплайн проверен на локальной тестовой странице.)

8. УСТРАНЕНИЕ НЕПОЛАДОК
-----------------------
- Значок есть, но запись не стартует, в панели ERROR: прочитайте причину в красном блоке.
  Частые: страница chrome:// или Chrome Web Store (их захватывать нельзя), вкладка закрыта,
  политика организации блокирует tabCapture, не хватает места на диске.
- "ARMED", но сразу PRIVACY PAUSED: скрипт страницы не внедрился. Обновите вкладку (F5)
  или нажмите "Remember this site".
- Скриншот в режиме Screenshot-only не делается: Chrome требует действия пользователя на
  вкладке. Нажмите значок ReproDesk на вкладке или используйте Alt+Shift+S.
- Нет Save Last Replay: кнопка работает в Armed (с видео). Видео можно выключить в настройках
  ("Video capture" -> режим Screenshot-only при следующем включении).
- Расширение не обновилось после пересборки: chrome://extensions -> кнопка обновить у ReproDesk.
- Полностью сбросить данные: chrome://extensions -> Удалить расширение (локальные данные удалятся).
